# SQL Practical Assignment

## Environment

- **DBMS:** PostgreSQL 18
- **Database:** Pagila
- **SQL Client:** DBeaver
- **Database Source:** https://github.com/devrimgunduz/pagila

## How to Run

1. Prepare and start a PostgreSQL 18 instance with the Pagila sample database loaded.
2. Open DBeaver and connect to the Pagila database.
3. Open the `.sql` assignment file in the SQL Editor.
4. Execute the queries individually.

The file contains seven SQL queries (Q1–Q7). All queries are read-only and do not modify the database.
